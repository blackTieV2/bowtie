# Operational Knowledge Fabric (OKF) — Index

Approved, durable, Git-tracked project knowledge. Nothing lands here without passing the memory write gate (`_config/memory-policy.yaml`).

| Area | Path | Contents |
|---|---|---|
| Domains | `domains/` | Subject-area knowledge (bow-tie methodology, risk matrices, incident analysis) |
| Systems | `systems/` | Knowledge about the app being built and its modules |
| Datasets | `datasets/` | Reference data (lookup tables, effectiveness scales) |
| Decisions | `decisions/` | Approved decision/judgment records |
| Episodes | `episodes/` | Approved episodic records (what happened, what worked) |
| Relationships | `relationships/` | Supersession/contradiction/support link register |
| Playbooks | `playbooks/` | Approved procedures, incl. the failure-pattern library |
| References | `references/` | Curated pointers to raw evidence and external sources |

Chronological log of knowledge events: `log.md`.

> Authority note: even approved knowledge is outranked by explicit current human instruction, verified live state, and PROJECT_STATUS.md (see `_config/authority-policy.yaml`).
