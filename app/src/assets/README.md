# Local report font

NotoSans-Regular.ttf is an unmodified open-source font from the Noto Project, licensed under SIL OFL 1.1 (NotoSans-LICENSE.txt). Source: https://github.com/notofonts/noto-fonts/blob/main/hinted/ttf/NotoSans/NotoSans-Regular.ttf

SHA-256: b85c38ecea8a7cfb39c24e395a4007474fa5a4fc864f6ee33309eb4948d232d5

The application loads these local bytes and embeds them in SVG/PDF/DOCX exports. It does not download fonts at runtime. The frontend family alias does not modify the font. No legacy application assets are used.
