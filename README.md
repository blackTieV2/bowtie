# bowtie

Clean-room reimplementation of the documented behavior of an end-of-life bow-tie risk-analysis desktop application, as a modern 64-bit, multiplatform, fully offline desktop app.

## Status

Repository governance bootstrap. No application code yet. See `PROJECT_STATUS.md`.

## For agents (human or AI)

Start here, in order:

1. `AGENTS.md` — canonical operating rules
2. `PROJECT_STATUS.md` — current stage, holds, next safe action
3. `CONTEXT.md` — stage router
4. The selected stage contract in `stages/`

The behavioral specification extracted from the legacy manuals lives in `stages/01-intake/references/spec/`. The first build prompt lives in `stages/04-build/references/REBUILD-MASTER-PROMPT.md`.
