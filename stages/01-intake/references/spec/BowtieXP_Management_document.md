Taking the next step: BowTieXP add-ons
Once a company has built BowTies and has incorpo-
rated them in the organisation, there are other appli-
cations possible with the information that is now in
the BowTies. In order to accommodate these exten-
sions, several add-ons were created for BowTieXP.



   BowTieXL is an add-on that allows users to quantify
   a BowTie and build models on top of the BowTies.
   BowTieXL introduces a Microsoft Excel compatible
   spreadsheet into BowTieXP, which exposes all the
   information in the case file as tabular data in this
   spreadsheet. This allows you to use that data to do
   spreadsheet calculations, based on that data, and
   feed the results back into your bow-tie model.




                                                         With the Black BowTieXP add-on users can map in-
                                                         cidents onto BowTies, to complete the circle and
                                                         truly combine proactive and reactive risk manage-
                                                         ment. You can map an infinite numbers of incidents
                                                         into a single case file, allowing you to distill synoptic
                                                         and relevant reports including overviews about –
                                                         amongst others – common causes of incidents.




    The SharePoint Enterprise add-on enables advanced Document Man-
    agement of the BowTie files. This is especially convenient in larger
    organisations and teams where there needs to be a central storage
    location for BowTies. Microsoft SharePoint is a server solution where
    files can be managed on an intranet or internet environment.

BowTieXL is a platform that allows you to create
your own ideas and methods of analysing risks.
Using Microsoft Excel-compatible spreadsheets,
this unique software has broken all the rules,
giving you the freedom and flexibility to build
and manipulate data in BowTie diagrams almost
as freely as Excel will allow. Initially developed
as a tool to allow quantification of BowTies, the
capabilities of BowTieXL has surprised even its
developers; users have already used BowTieXL
to create actual risk pictures, map multiple inci-
dents and audits, link a hazard register, simply
add or modify data fields and of course find a host
of ways to quantify the BowTie.

Generic Roadmap
This roadmap briefly outlines a typical path that is
taken to properly implement BowTies, with all of the
resources that are needed around it. Some are op-
tional, but most are normal practice with any good
implementation process.


1. Training of “super users”

•      Users attend a BowTie Master Class
•      Optionally use a BowTie review service on the first BowTies

2. Develop company BowTie guideline

•      BowTie Philosophy (Why and how to use BowTie, When are BowTies required, 		
       Level of detail)
•      BowTie development process (Steps, who should join, how to organise, review 		
       process)
•      Implementation and communication (link with SMS, use in training and risk 		
       awareness, incorporate in JSA / Permit to Work, use in investigations and Auditing)
•      Barrier Management (Barrier Effectiveness, Performance Standards, status info)
•      Generic BowTies / BowTie Repository / Best Practice BowTies
•      Align with other requirements like Safety Cases and Cumulative Risk guidelines
•      Create company template/risk library

3. Selection of BowTie tools (based on 2) e.g.:

•      BowTieXP advanced for “super users”
•      BowTie Navigator or Standard for reviewers of BowTies
•      BowTie Webviewer to communicate to the organisation
•      XL add-on for further growth like linking actual data to barriers in BowTieXP and/or
       developing Incident BowTies
•      Other (e.g. Work BowTie tool for JSA’s, Questionnaire tool for audit & incident 		
       questionnaires)

4. Set-up and roll-out of a BowTie development program
(locations/assets, Generic BowTies, ...)
